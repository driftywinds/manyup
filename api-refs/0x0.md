# 0x0.st — API reference

> Reference for the API surface manyup uses. Sourced from the operator's own
> documentation at <https://0x0.st>, captured 2026-10-25.

| | |
|---|---|
| **Base / upload URL** | `https://0x0.st` |
| **Auth** | None |
| **Upload method** | `multipart/form-data` POST |
| **Max file size** | 512 MiB |
| **Retention** | minimum 30 days, maximum 1 year |

The Null Pointer is an anonymous temporary file host run by a single operator in
Germany. There are no accounts and no API keys.

---

## Uploading

`POST https://0x0.st` with `multipart/form-data`.

Valid fields:

| Field | Content | Remarks |
|---|---|---|
| `file` | file data | what manyup sends |
| `url` | remote URL | mutually exclusive with `file`; the remote must send `Content-Length` |
| `secret` | *(ignored)* | presence produces a longer, hard-to-guess URL |
| `expires` | hours **or** ms since epoch | maximum lifetime |

```bash
curl -F'file=@yourfile.png' https://0x0.st
curl -F'file=@yourfile.png' -Fsecret= https://0x0.st
curl -F'file=@yourfile.png' -Fexpires=24 https://0x0.st
```

**Response:** `200` with the download URL as **plain text**, not JSON:

```
https://0x0.st/abc.txt
```

### Retention

Retention is not fixed: it scales with file size.

```
min_age = 30 days
max_age = 1 year
max_size = 512 MiB
retention = min_age + (min_age - max_age) * pow((file_size / max_size - 1), 3)
```

A tiny file lives ~1 year; a file at the 512 MiB ceiling lives ~30 days. Expired files
are removed within a minute.

## Managing files

The upload response includes an `X-Token` header when the file is new or was expired.
Use it to manage the file by POSTing to the file's own URL:

| Field | Content | Remarks |
|---|---|---|
| `token` | from the `X-Token` response header | required |
| `delete` | *(ignored)* | removes the file |
| `expires` | hours or epoch-ms | changes the expiration |

```bash
# delete
curl -Ftoken=token_here -Fdelete= https://0x0.st/abc.txt

# extend
curl -Ftoken=token_here -Fexpires=3 https://0x0.st/abc.txt
```

A custom file name can be appended to any URL: `https://0x0.st/aaa.jpg/image.jpeg`.

## Errors

| Status | Meaning |
|---|---|
| `4xx` | rejected upload; body carries the reason |
| `5xx` | server-side failure |

Blocked clients receive an HTML page rather than JSON. There is no documented rate-limit
header.

---

## Service rules that affect integration

- Use a user agent that identifies the client. **Mimicking a browser is detected and
  blocked automatically.**
- Uploads are for files, not backups, CI artifacts, or automated mass uploads.
- Uploader IP and user agent are stored for moderation.

---

## manyup integration notes

`internal/services/0x0.go` streams the file into the `file` field using an `io.Pipe` and
returns the plain-text body (trimmed) as the result URL. `SupportsLargeUpload()` is
`false` because of the 512 MiB cap. No credentials are read.
