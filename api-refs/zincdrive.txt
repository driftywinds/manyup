
api API v1
API Documentation

Upload files, manage your content, and access your account programmatically.
Getting Started

All API requests require an API key for authentication. You can generate your API key from Settings.

Base URL
https://zincdrive.com/api/v1

Authentication

Pass your API key via the X-API-Key header or as a query parameter:
# Header method (recommended)
X-API-Key: your_api_key_here

# Query parameter method
https://zincdrive.com/api/v1/account?api_key=your_api_key_here
warning

Rate Limit: 60 requests per minute. Keep your API key secret — do not share it publicly.

POST
/api/v1/upload/url

Upload a file by URL. Creates an async task that downloads the file and uploads it to your account. Poll the status endpoint to track progress.

Parameters
url
required
string The URL to download the file from.
folder_id
integer Upload into a specific folder.
visibility
integer 1 = public, 0 = private, 2 = unlisted. Default: 1 (public).

Example Request

curl -X POST -H "X-API-Key: YOUR_KEY" \
  -d "url=https://example.com/file.zip" \
  -d "visibility=1" \
  https://zincdrive.com/api/v1/upload/url

Direct S3 Upload

ZincDrive supports high-performance direct-to-storage uploads. Files are streamed directly to our storage nodes, bypassing the main application server. This supports massive file sizes up to 10GB.
POST
/api/v1/s3/sign

Get a presigned PUT URL for single-part upload. This is the fastest method for files up to 4GB.

Parameters
filename
required
string Original filename including extension.
type
string MIME type of the file (e.g. video/mp4).

Example Request

curl -X POST -H "X-API-Key: YOUR_KEY" \
  -d "filename=video.mp4" \
  https://zincdrive.com/api/v1/s3/sign

WORKFLOW
Multipart Upload (up to 10GB)

For files up to 10GB, use the multipart workflow. This allows you to upload parts in parallel and resume interrupted transfers.
Step 1: Initiate
POST /s3/multipart

Returns an uploadId and key.
Step 2: Sign & Put
GET /s3/multipart/{id}/{part}

Get a URL for each part, then PUT the bytes.
Step 3: Complete
POST /s3/multipart/{id}/complete

Send the list of ETags to finish the upload.
POST
/api/v1/s3/confirm

MANDATORY: Call this after the S3 transfer (PUT) is finished to create the file entry in your account.

Parameters
key
required
string The object key returned by the sign or multipart endpoint.
filename
required
string The original filename.
size
required
integer The total file size in bytes.
folder
integer Folder ID.
visibility
integer 1 = public, 0 = private, 2 = unlisted.

Example Request

curl -X POST -H "X-API-Key: YOUR_KEY" \
  -d "key=uploads/users/..." \
  -d "filename=video.mp4" \
  -d "size=12345678" \
  https://zincdrive.com/api/v1/s3/confirm

Complete Examples (Direct S3)

Python (Single-Part)

import requests, os

def upload_file(filepath, api_key, api_base="https://zincdrive.com/api/v1"):
    filename = os.path.basename(filepath)
    size = os.path.getsize(filepath)
    
    # 1. Get signed URL
    r = requests.post(f"{api_base}/s3/sign", 
                     headers={"X-API-Key": api_key}, 
                     data={"filename": filename})
    signed = r.json()
    
    # 2. Upload to S3
    with open(filepath, "rb") as f:
        requests.put(signed["url"], data=f, headers=signed["headers"])
    
    # 3. Confirm
    r = requests.post(f"{api_base}/s3/confirm",
                     headers={"X-API-Key": api_key},
                     data={
                         "key": signed["key"],
                         "filename": filename,
                         "size": size
                     })
    return r.json()["download_link"]

link = upload_file("/path/to/video.mp4", "YOUR_API_KEY")
print(f"File uploaded: {link}")

Node.js (Single-Part)

const fs = require("fs");
const path = require("path");
const fetch = require("node-fetch"); // npm i node-fetch

async function uploadFile(filepath, apiKey, apiBase = "https://zincdrive.com/api/v1") {
    const filename = path.basename(filepath);
    const size = fs.statSync(filepath).size;

    // 1. Get signed URL
    const resSign = await fetch(`${apiBase}/s3/sign`, {
        method: "POST",
        headers: { "X-API-Key": apiKey, "Content-Type": "application/x-www-form-urlencoded" },
        body: `filename=${encodeURIComponent(filename)}`
    });
    const signed = await resSign.json();

    // 2. Upload to S3
    await fetch(signed.url, {
        method: "PUT",
        headers: signed.headers,
        body: fs.createReadStream(filepath)
    });

    // 3. Confirm
    const resConfirm = await fetch(`${apiBase}/s3/confirm`, {
        method: "POST",
        headers: { "X-API-Key": apiKey, "Content-Type": "application/x-www-form-urlencoded" },
        body: `key=${encodeURIComponent(signed.key)}&filename=${encodeURIComponent(filename)}&size=${size}`
    });
    const confirm = await resConfirm.json();
    return confirm.download_link;
}
